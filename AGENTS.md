# Working in V3Code

Keep changes focused and read the current file before editing it. Preserve existing
copyright, license, SPDX and attribution notices exactly; a contribution may add a
notice for new work but must not rewrite or remove an earlier one.

Do not add copied code, generated assets, themes, prompts or data without recording
the source, exact version or commit, local path and license. If provenance is unclear,
stop and flag the file instead of guessing.

For a pull request:

- explain the problem and the change in plain language;
- run the smallest relevant tests plus the documented build checks for the area;
- include a screenshot or short recording for visible interface work;
- say what was not tested;
- disclose material AI assistance and review the result yourself.

Repository access does not authorize signing, publishing, deployment or update-feed
changes. Those are maintainer release operations.
