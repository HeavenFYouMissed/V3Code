# Third-party icon assets

Icons and semantically unchanged theme mappings from Pierre VS Code Icons 0.0.9
(`pierrecomputer.pierre-vscode-icons`), Complete colored tier.

- Source: https://github.com/pierrecomputer/vscode-icons/tree/v0.0.9
- Official artifact: https://marketplace.visualstudio.com/_apis/public/gallery/publishers/pierrecomputer/vsextensions/pierre-vscode-icons/0.0.9/vspackage
- Decompressed VSIX SHA-256: `9b66d6c0a965350e3e686ee750709dfbb2d35e04344264816711ef1b72378b60`
- License: MIT, retained verbatim in LICENSE.md.

Only static SVGs and JSON theme mappings are included; no extension code or
runtime dependencies. Original shapes are preserved. Markdown and JSON fills are
adapted to the reference palette: dark green #5ecc71 / orange #ffa359 and light
green #199f43 / orange #d47628. Other dark and light palettes are unchanged.
JSON indentation is normalized to repository tabs; mapping values are unchanged.
